# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, contact the maintainer via WhatsApp: **+92 316 7417135**

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected version or commit.
- Any relevant output or evidence.

You should receive an initial response within 48 hours.

## Responsible Disclosure

We ask that you:
- Give us reasonable time to investigate and remediate before public disclosure.
- Avoid accessing or modifying data that does not belong to you.
- Act in good faith and avoid degrading service availability.

## Scope

This policy applies to the `php-security-audit-toolkit` project itself.
It does not cover vulnerabilities in scanned PHP applications or in
third-party dependencies used by those applications.
